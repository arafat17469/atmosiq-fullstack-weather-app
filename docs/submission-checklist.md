## Suggested project description

AtmosIQ is a Next.js/TypeScript full-stack weather app using live Open-Meteo APIs,
Prisma, and PostgreSQL. It provides location search, geolocation, five-day forecasts,
hourly charts, maps, comparison, and rule-based travel advice. Users can create, read,
update, delete, and export saved weather requests as CSV or JSON. Inputs and date ranges
are validated and provider errors are shown clearly. Both Tech Assessments #1 and #2
are implemented; confirm deployed persistence before claiming end-to-end completion.
